## Architecture & Patterns

- **Clean Architecture:** separating application logic from infrastructure.
- **Repository Pattern:** data access behind interfaces in the expense tracker.
- **Modular Monolith:** business modules within Zaara's ASP.NET Core host.
- **Dependency Injection:** registered services and repositories supplied through constructor injection.
- **REST & Minimal APIs:** endpoints backed by SQL Server, with EF Core or Dapper for data access.

A compact view of Zaara Royal Catering's application flow:

```text
Angular
   |
ASP.NET Core Minimal APIs
   |
Business modules
(application / domain)
   |
Infrastructure (EF Core)
   |
SQL Server
```
